# Yarbrough Health & Wellness website

Static website for Yarbrough Health and Wellness, personal training with Lucie Yarbrough in Winston-Salem, NC.

## Structure

- `index.html`: homepage
- `css/site.css`: shared styles (Cormorant Garamond + Jost, plum and blush palette)
- `img/`: site photos
- `blog/`: blog index and posts (moved over from the old Wix site)
- `terms/`, `refunds/`, `privacy/`, `accessibility/`: policy pages

## Hosting

Plain HTML and CSS with no build step. Deploy on Cloudflare Pages with:

- Build command: *(none)*
- Build output directory: `/`
- Production branch: `main`
